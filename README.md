# Snake

A polished classic Snake game built with Python and Pygame.

## Setup

Install dependencies:

```powershell
python -m pip install -r requirements.txt
```

If you are using MSYS2 Python, install Pygame with pacman instead:

```powershell
pacman -S mingw-w64-x86_64-python-pygame
```

## Run

```powershell
python src/main.py
```

## Controls

- Arrow keys or WASD: move
- P: pause or resume
- Space or Enter: start or restart
- Escape: quit
